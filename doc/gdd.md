# Game Design Document

## 概述

- 类型：单键操作 / 解谜 / 回合制
- 视角：固定正交俯视（顶视图）
- 玩法：控制滑块在离散格子上滑动，利用物理规律规划路径到达终点

## 操作

当滑块静止时，玩家可以进行以下操作：

- 短按 (按压后在 0s-0.2s 之内抬起)：滑块按照顺时针顺序改变一次面朝方向
- 长按 (按压后在 0.2-3s 之内抬起)：滑块获得目标动能
- 久长按 (按压超过 3s 立即触发)：重置关卡

目标动能大小与按压时长无关，即每次长按都会固定获得 `level.target_kinetic_energy`

当滑块运动时，玩家可以进行以下操作：

- 久长按 (按压超过 3s)：重置关卡

## 重置关卡

- 玩家主动久长按
- 滑块死亡

重置关卡会重置所有关卡元素状态

## 关卡元素

关卡元素在 z 轴方向上分为两层

- 地面层 obj.position.z=-1
    - 地面 *Ground*
    - 虚空 *TheVoid*
- 物体层 obj.position.z=0
    - 滑块 *Block*
    - 墙体 *StaticBlock*
    - 钥匙 *Key*
    - 终点 *EndZone*

逻辑层上只关心对象的**能量**，即动能，质量、速度、位置等等属性仅为表现层而存在
逻辑层永远是离散化的步进结算

滑块的体积大小为 `1m*1m*1m`，质量大小为 `1kg`
滑块的面朝方向 `block.facing_dir` 默认为 `(0, 1)`
滑块的质心 `block.centroid` 为面朝方向边的中心
滑块的位置 `block.position` 为几何中心的位置
对于短按操作，滑块改变面朝方向在逻辑层上是瞬间改变，在表现层上是绕着几何中心旋转
对于长按操作，滑块的速度 `block.velocity`，方向为面朝方向，大小由动能大小反推

设 `block.current_kinetic_energy` 为滑块的当前动能

地面的上表面面积大小为 `1m*1m`
地面的位置 `ground.position` 为几何中心的位置
滑块是否位于地面相当于滑块的几何中心是否位于地面的几何中心
滑块是否经过地面相当于滑块的质心是否经过地面的几何中心
滑块经过地面，面朝方向不变，速度方向不变，动能变化量为 `ground.kinetic_energy_delta`

当滑块经过地面时，令 `cke := block.current_kinetic_energy + ground.kinetic_energy_delta`

- 当 `cke < 0` 滑块的动能不足以克服地面摩擦而死亡
- 当 `cke = 0` 滑块静止
- 当 `cke > 0` 滑块继续运动

地面层除了地面的其他格子都是虚空
虚空的位置 `the_void.position` 为几何中心的位置
滑块是否位于虚空相当于滑块的几何中心是否位于虚空的几何中心
滑块是否经过虚空相当于滑块的质心是否经过虚空的几何中心
当滑块位于虚空时，或当滑块经过虚空时，滑块死亡

墙体的体积大小为 `1m*1m*1m`
墙体的位置 `static_block.position` 为几何中心的位置
滑块是否碰撞墙体相当于滑块的速度方向边是否碰撞墙体的边
滑块碰撞墙体，面朝方向不变，速度方向相反，`block.current_kinetic_energy` 变为原来的 `e_block * e_static_block` 倍

- `e_block`：滑块的碰撞边的绝对恢复系数
- `e_static_block`：墙体的碰撞边的绝对恢复系数

绝对恢复系数的数值会设计成要么滑块可以恰好静止，要么滑块会死亡

钥匙的体积大小为 `1m*1m*1m`
钥匙的位置 `key.position` 为几何中心的位置
滑块是否触碰钥匙相当于滑块的几何中心是否位于钥匙的几何中心
只要滑块触碰钥匙，就能解锁通关条件，无论滑块是运动经过，还是恰好停下

终点的体积大小为 `1m*1m*1m`
终点的位置 `end_zone.position` 为几何中心的位置
只有滑块静止终点，才能通关，即使滑块运动经过，也不能通关
